# Daily — чекер дел

Личный трекер: ежедневные дела по саморазвитию, разовые задачи и журнал с отметками времени. Работает с телефона и компьютера, ставится на домашний экран как приложение.

## Что внутри

- **Сегодня** — ежедневные дела по направлениям (программирование, английский, трейдинг, SQL) с расписанием по дням недели, прогрессом и сериями 🔥. Стрелками можно отметить вчерашний день.
- **План дня** — блоки времени «с — до» (разовые или повторяющиеся по дням недели), свободные окна между ними, подсветка текущего блока.
- **Проекты** — этапы со сроками, прогресс, дедлайн проекта; на «Сегодня» — ближайший шаг по каждому активному проекту.
- **Календарь** — месяц с дедлайнами, план и дедлайны выбранного дня, ближайшие 14 дней и просроченное.
- **Разовые дела** — со сроком или без; просроченные подсвечиваются, будущие свёрнуты в «Запланировано».
- **Журнал** — записи с автоматическим временем, пометка «Важное», поиск, редактирование времени и текста. `Ctrl/⌘ + Enter` — записать.
- **История** — тепловая карта за 16 недель и статистика по каждому делу за 30 дней.
- **Настройки** — список дел, синхронизация, тема, экспорт/импорт JSON.

## Синхронизация

Данные лежат в `localStorage` и, если подключить токен, в приватном GitHub Gist (`daily-tracker-data`). В репозиторий данные не попадают.

1. Создай classic-токен со scope **gist**: <https://github.com/settings/tokens/new?scopes=gist&description=Daily%20tracker>
2. Вставь его в «Настройки → Синхронизация» на каждом устройстве.

Каждая запись хранит время изменения, при синхронизации побеждает более свежая версия — правки с разных устройств не затирают друг друга.
