# Daily — календарь дел

Личный трекер в виде календаря. Работает с телефона и компьютера, ставится на домашний экран как приложение.

## Как устроено

- **Один экран — месяц.** У каждого дня кольцо выполнения: заполняется по мере закрытия дел, зелёное — всё сделано. Красная точка — в прошедшем дне что-то осталось. Точки на будущих днях — запланированные дела и дедлайны проектов.
- **Нажал на день — под месяцем его дела.** Сначала дела со временем (со «свободными окнами» между ними), потом остальные. Внизу — быстрый ввод: можно сразу со временем, «19:00-21:00 Python».
- **Всё — это задача.** У задачи может быть дата, время «с — до», повтор по дням недели, проект и заметки. Ежедневные дела — это просто повторяющиеся задачи.
- **Хвосты** — незакрытые разовые дела с прошлых дней показываются наверху «Сегодня».
- **Без даты** — то, что не забыть, но срока пока нет.
- **Заметки дня** — журнал с автоматическим временем.
- **План на день** — у ежедневных дел есть «минимум» и шаги на конкретный день. Их составляет Claude в файле `plan.json` этого репозитория; свои шаги можно добавить прямо в карточке дня. Там же можно поменять время дела только на этот день.
- **Проекты** (иконка папки) — задачи проекта, прогресс, дедлайн и заметки.

## Синхронизация

Данные лежат в `localStorage` и, если подключить токен, в секретном GitHub Gist (`daily-tracker-data`). В репозиторий данные не попадают.

1. Создай classic-токен со scope **gist**: <https://github.com/settings/tokens/new?scopes=gist&description=Daily%20tracker>
2. Вставь его в «Настройки → Синхронизация» на каждом устройстве.

У каждой записи есть время изменения; при синхронизации побеждает более свежая версия, так что правки с разных устройств не затирают друг друга.

## Стек

Чистые HTML/CSS/JS без сборки, PWA (manifest + service worker). Хостинг — GitHub Pages из ветки `main`.
